What does a UTIL table mean?

Each row gives the minimum cost of the sender's subtree, conditional on the listed ancestor channels. The sender has minimized over its own channel. A row is a possible context, not a committed assignment. Forbidden means no feasible choice exists for that context.

These costs are synthetic scores, not throughput or measured interference. DPOP sends conditional tables; it does not gradually recolor this map during UTIL.

Data and reproducibility

Municipal boundaries: IBGE 2022. Membership: AMEP. One hypothetical agent per municipality. Four abstract channels, each agent's costs: 0, 10, 20, 30. Root: Curitiba. Reliable FIFO transport; playback speed has no simulated-time meaning.

This is an executable integration example, not a frozen experimental study. The embedded trace includes complete UTIL tables; the visible table shows its first 12 rows.
